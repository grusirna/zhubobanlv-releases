# 统一版使用说明

统一版 [0.1.15](https://github.com/grusirna/zhubobanlv-releases/releases/tag/v0.1.15) 已正式发布。请核对发行页版本和附件校验和。

## 安装与更新

下载 Windows x64 安装器，核对发行页提供的 SHA-256 后运行。主安装器尚未签名，Windows 可能提示未知发布者。应用内更新入口打开 codexon 资源页供手动下载；GitHub 发行与 codexon 版本分别以各通道的实际状态为准。

旧统一版可直接升级并继续使用原数据；升级前可自行备份重要文稿和配置。六个已退役的独立应用数据不会自动合并或覆盖。卸载保留用户数据。

## 六项功能

| 页面 | 使用入口 |
| --- | --- |
| 麦克风优化 | 选择输入／输出设备和处理方案，在声音调节中调整参数及试听 |
| 音效快捷键 | 添加音效，点击卡片试听，拖到键盘或打开绑定弹窗配置快捷键 |
| 窗口缩放 | 选择目标窗口，编辑尺寸／位置后点击应用调整 |
| 音视频录播 | 在播放库选择本地媒体，通过播放台及输出设置控制输出 |
| 文稿提词 | 在文稿编排中管理稿件，在提词设置中调整提词窗口及识别组件 |
| 画面增强 | 选择目标和档案，调整画面参数后启动增强 |

配置、媒体库索引和文稿保存在本机。提词识别模型不随主安装器打包，已安装模型可继续使用。

独立模型发行已撤下，0.1.15 的旧模型安装入口暂不可用。本地 0.1.16 候选已提供“文稿提词器 → 提词设置 → 识别模型”的检测、一键安装、进度、取消和重试，安装后直接完成配置，无需先下载 ZIP 或运行脚本；该候选尚未正式发布，当前正式下载仍为 0.1.15。

## 设备与验收边界

麦克风路由、画面增强、窗口控制和录播输出受设备、目标程序及权限影响。专用硬件及持续真实口播专项尚未逐项实测；先在非正式直播环境确认实际效果。具体构建、安装和界面验收结果随正式发行说明提供。
