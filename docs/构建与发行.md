# 构建与发行

应用源码保存在私有仓库；本公共仓库保持独立 Git 历史，保存受控构建及下载材料。正式安装器通过验收后才公开。

维护者在 Actions 手动运行 Windows build and draft，输入私有 main 的完整 40 位提交 SHA 和对应产品版本。工作流只允许仓库所有者从公共 main 发起；来源和版本不匹配立即停止。

builder 用只读 deploy key 检出源码，发布 job 仅能写本公共仓库。候选和完整诊断加密传给验收主机，公共日志仅显示允许公开的阶段结果。验收私钥须与 build-transfer-public.pem 配对，保存在维护主机受限的凭据目录；私钥、源码、用户数据、编译缓存、日志和 source map 不进入本仓库。

维护主机先核对构建报告、来源、版本与安装器 SHA-256，再完成同一安装器的后台、六页面、Windows Sandbox 全新安装、升级、数据保留和卸载验收。全部门禁通过后，使用私有项目的发行入口开放正式 Release，并重新下载核对完整哈希。模型和第三方运行组件分别发行，不能把它们的发布成功当作主应用已通过验收。

正式版本附件不覆写。同版本重试只补同一已验收候选的缺失材料；不同安装器必须使用新版本。构建附件保留 3 天。失败诊断使用相同加密通道，不在公共日志打印私有源码或凭据。

本仓库不建立 GitHub Pages 或独立网站。GitHub 发行不修改 codexon 生产部署。
